# NewsApp - Мобильное новостное приложение

Кроссплатформенное мобильное новостное приложение, построенное на React Native и Expo, с современной архитектурой и полным функционалом.

## 🚀 Возможности

### Основной функционал
- **Лента новостей** - Просмотр последних новостей из NewsAPI с бесконечной прокруткой
- **Поиск и фильтрация** - Поиск новостей по ключевым словам
- **Детали статьи** - Просмотр полных статей с интеграцией WebView
- **Избранное** - Сохранение статей локально с помощью AsyncStorage
- **Биометрическая аутентификация** - Безопасный вход с Touch ID/Face ID
- **Push-уведомления** - Локальные уведомления о новостях
- **Управление файлами** - Загрузка и скачивание файлов с предпросмотром

### Технические особенности
- 📱 Кроссплатформенность (iOS, Android, Web)
- 🎨 Чистый минималистичный дизайн в стиле NY Times
- 🌐 Адаптивный веб-макет с сеткой
- 💾 Оффлайн-хранилище с AsyncStorage
- 🔐 Биометрическая безопасность
- 📤 Функционал загрузки/скачивания файлов
- 🔔 Push-уведомления

## 🚀 Начало работы

### Требования
- Node.js (v18 или выше)
- npm или yarn
- Expo CLI
- iOS Simulator (для Mac) или Android Studio (для разработки под Android)

### Установка

1. **Клонируйте репозиторий**
```bash
   git clone https://github.com/Tair15/Taishanov-News.git
   cd NewsApp
```

2. **Установите зависимости**
```bash
   npm install
```

3. **Настройте переменные окружения**
   
   Создайте файл `.env` в корневой директории:
```env
   EXPO_PUBLIC_NEWS_API_KEY=ваш_ключ_newsapi
```
   
   Получите бесплатный API ключ на [NewsAPI.org](https://newsapi.org/)

4. **Запустите сервер разработки**
```bash
   npm start
```

### Запуск приложения

#### Web
```bash
npm run web
```
или нажмите `w` в Expo CLI

#### Expo Go (Тестирование на мобильном)
1. Установите приложение Expo Go на телефон
2. Отсканируйте QR-код из терминала
3. Приложение загрузится на вашем устройстве

## 📱 Руководство по функциям

### Аутентификация
- **Биометрический вход**: Используйте Touch ID/Face ID на поддерживаемых устройствах 
- **Ручной вход**: Альтернативный вход без биометрии
- **Безопасный выход**: Очистка данных сеанса при выходе

### Лента новостей
- **Бесконечная прокрутка**: Автоматическая загрузка новостей при прокрутке
- **Поиск**: Найдите статьи по ключевым словам
- **Адаптивная сетка**: Макет в 2-3 колонки на больших экранах
- **Информация об источнике**: Просмотр издателя и даты публикации

### Детали статьи
- **Полный контент**: Чтение статей внутри приложения
- **WebView**: Открытие оригинальной статьи во встроенном браузере
- **Сохранение в избранное**: Закладка статей на потом
- **Адаптивный макет**: Оптимизирован для всех размеров экрана

### Избранное
- **Постоянное хранилище**: Сохраненные статьи остаются после перезапуска
- **Удобное управление**: Удаление статей из избранного
- **Единый макет**: Согласованный дизайн с лентой новостей

### Менеджер файлов
- **Загрузка файлов**: Выбор из галереи, камеры или документов
- **Скачивание файлов**: Сохранение файлов на устройство
- **Просмотр галереи**: Просмотр загруженных файлов с предпросмотром
- **Обмен файлами**: Делитесь файлами с другими приложениями

### Уведомления
- **Локальные уведомления**: Планирование напоминаний
- **Мгновенные оповещения**: Отправка немедленных уведомлений
- **Пользовательские сообщения**: Настройка содержимого уведомлений

## 🏗️ Архитектура

### Feature-Sliced Design (FSD)
Проект следует методологии FSD для лучшей поддерживаемости:
```
features/          # Бизнес-функции
├── news/         # Всё, связанное с новостями
├── auth/         # Логика аутентификации
├── favorites/    # Функционал избранного
└── fileUpload/   # Файловые операции

shared/           # Переиспользуемый код
├── ui/          # Универсальные компоненты
├── lib/         # Утилиты и сервисы
└── types/       # Общие типы

pages/           # Экраны приложения
app/             # Инициализация приложения
```

### Управление состоянием
- **Redux Toolkit**: Глобальное управление состоянием
- **RTK Query**: Серверное состояние и кеширование
- **AsyncStorage**: Локальное сохранение
- **React State**: Состояние на уровне компонентов

## 🐛 Устранение неполадок

### Частые проблемы

**Проблема**: Запросы API не работают
- **Решение**: Проверьте файл `.env` и убедитесь, что API ключ действителен

**Проблема**: Биометрическая аутентификация не работает
- **Решение**: Биометрия работает только на физических устройствах, не в симуляторах

**Проблема**: WebView не отображается на веб-платформе
- **Решение**: Статьи открываются в новой вкладке на веб-платформе (ожидаемое поведение)

**Проблема**: Проблемы с кешем
- **Решение**: Запустите `npx expo start --clear` для очистки кеша
